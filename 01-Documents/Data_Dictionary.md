# Data Dictionary

## FactSales

| Column | Description |
| SalesID | Sales transaction identifier |
| ProductID | Product reference |
| RetailerID | Retailer reference |
| CustomerID | Customer Reference |
| DateKey | Date reference |
| UnitsSold | Quantity sold |
| Revenue | Total revenue |
| Profit | Profit amount |

| Column | Description |
| PromotionID | Promotion identifier |
| PromoSpend | Promotion investment |
| IncrementalSales | Additional sales generated |

## FactMarketShare

| Column | Description |
